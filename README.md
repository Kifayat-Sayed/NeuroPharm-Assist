# NeuroPharm Insight

You are a Senior Full Stack Engineer, Senior UI/UX Designer, Healthcare Software Architect, and React Expert. We are building a real-world clinical web application called: NeuroPharm Assist This is NOT a generic CRUD project. It is a professional Clinical Decision Support Platform (CDSS) developed as a PharmD research project. The software should look comparable to Epic, Cerner, Oracle Health, or Philips clinical applications, while remaining modern and visually appealing.

PROJECT GOAL Replace Google Forms used during pharmacist-led neuropathic pain assessment with a professional web application. The platform should help pharmacists conduct standardized clinical assessments using the DN4 questionnaire, document medication reviews, record pharmacist interventions, and generate professional clinical reports. The emphasis is on usability, workflow efficiency, and research-quality data collection.

TECH STACK Next.js 15 TypeScript Tailwind CSS shadcn/ui Framer Motion Lucide React React Hook Form Zod Do NOT add any backend. Do NOT use Firebase. Do NOT use Supabase yet. Do NOT implement authentication. Everything should use mock data.

DESIGN STYLE Modern healthcare software. Minimal. Clean. Premium. Soft shadows. Rounded corners. White cards. Blue medical accents. Excellent typography. Lots of spacing. Professional. NO generic admin dashboard appearance. NO Bootstrap look. NO Material UI look.

RESPONSIVE Desktop first. Tablet second. Mobile compatible.

DESIGN SYSTEM Create reusable components. Buttons Cards Inputs Tables Badges Progress Indicators Sidebar Navbar Search Bar Stat Cards Timeline Stepper

APPLICATION STRUCTURE Dashboard Patients Patient Profile New Assessment DN4 Assessment Medication Review Recommendations Reports Settings

IMPORTANT Create ONLY the frontend. Use mock JSON data. No backend. No database. No authentication. Use best practices. Reusable architecture. Feature-based folder structure.
